# Подсказчик ходов

Веб-приложение: вводишь ходы соперника (тапами, перетаскиванием или скриншотом) — Stockfish 18 прямо в браузере показывает лучший ответ.

- Stockfish 18 (WASM, многопоточный через COOP/COEP из service worker; однопоточный — запасной вариант)
- до 3 лучших вариантов с оценкой, режим бесконечного анализа
- редактор позиции, загрузка FEN/PGN, отмена/повтор
- распознавание доски со скриншота (`js/vision.js`)
- работает офлайн, устанавливается как приложение (PWA)

Запуск локально: `python3 -m http.server 8765` и открыть http://localhost:8765
